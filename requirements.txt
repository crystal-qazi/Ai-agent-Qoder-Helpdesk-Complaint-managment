# MIME detection.  python-magic is pulled in on every platform: the
# app's ``detect_mime_type`` helper tries the C extension lazily and
# falls back to a header-based sniffer when libmagic is not present,
# so the dependency is a hard requirement on Linux (which ships the
# library as a system package) and optional on Windows/macOS.
#
# Linux:
#   ``pip install python-magic`` and ``apt-get install -y libmagic1``
# Windows:
#   ``pip install python-magic`` — a CPython extension is available on
#   PyPI for common releases; if it is unavailable the app still
#   enforces extension / size / filename validation via the fallback
#   sniffer in ``app/services/mime_detection.py``.
